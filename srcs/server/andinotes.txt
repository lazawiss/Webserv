206 Partial Content - response server sends when a client asks for only part of a resource
instead of the whole thing - using Range headers

Request side: 
GET /video.mp4 HTTP/1.1
Range: bytes=1000-1999 // range 

response side:
HTTP/1.1 206 Partial Content
Content-Range: bytes 1000-1999/50000
Content-Range: bytes start-end/total (total = full file)
Content-Length: 1000
Content-Type: video/mp4

<the 1000 bytes>

if range is invalid 416:
HTTP/1.1 416 Range Not Satisfiable
Content-Range: bytes */50000
